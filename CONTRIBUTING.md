# Contributing to MovieLens 32M Recommendation System

Thank you for your interest in contributing! We welcome contributions, bug reports, feature suggestions, and documentation improvements.

## Development Setup

1. **Fork and Clone the Repository**:
   ```bash
   git clone https://github.com/mightyalok00/movie-recommendation-system-scikit-learn.git
   cd movie-recommendation-system-scikit-learn
   ```

2. **Create a Virtual Environment**:
   ```bash
   python -m venv venv
   # On Windows:
   .\venv\Scripts\activate
   # On macOS/Linux:
   source venv/bin/activate
   ```

3. **Install Dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

4. **Run Unit Tests**:
   ```bash
   python main.py test
   ```

## Pull Request Guidelines

- Create a feature branch (`git checkout -b feature/awesome-feature`).
- Follow PEP 8 style conventions with type hints and docstrings.
- Ensure all unit tests pass before submitting (`python main.py test`).
- Open a Pull Request with a clear description of the changes.
